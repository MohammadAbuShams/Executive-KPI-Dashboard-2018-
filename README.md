# 📊 Executive KPI Dashboard (2018)

## 📌 Overview
This project delivers an **Executive KPI Dashboard** built using the Superstore dataset. The dashboard is designed for executives who need a **strategic, high-level view** of business performance without digging into spreadsheets.

## 🎯 Dashboard Highlights
- **Top-Level KPIs (2018):**
  - 💰 Sales  
  - 📈 Profit  
  - 📊 Profit Ratio  
  - 📦 Quantity Sold  
- **YoY Performance by Segment** – Track performance of Corporate, Consumer, and Home Office over time.  
- **Monthly Trend (2018)** – See month-to-month changes in sales and profit across segments.  
- **Category Performance** – Compare product categories side by side.  
- **Best Sub-Category by Segment** – Quickly identify the strongest sub-categories in each segment.  

## 🛠️ Tools Used
- **Tableau Public** → dashboard design and visualization  
- **MS Word / Google Docs** → sketches, wireframes, and text hierarchy  
- **Superstore Dataset** → provided in course resources
